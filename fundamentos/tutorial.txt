Variáveis na linguagem JS são dinamicamente tipada
- string
- number
- boolean

- fuction
- object

 Para criar uma constante usamos: const
 Para criar uma variável  podemos usar var ou let 
 var (obsoleto e inseguro (redeclarar a variável)) usar sempre o let 

 concatenação (união de textos com variáveis)

 FRAMEWORK

 Um framework é um conjunto de ferramentas, biblioteca e regras que facilita o desenvolvimento de software, forneceno
 uma estrutura pronta para o programador. O framework define um "esqueleto" do projeto, onde você preenche com seu código,
 seguindo padrões já estabelecido. Isso economiza tempo, evita a repetição de código e garante boas práticas.
 Um framework é como montar um hambúrguer em uma rede de fast food.
 Se um framework, você teria que moer carne, assar o pão, preparar os ingredientes e criar sua própria receita do zero.

 ___________________________________________________________________________________________________________________

Array ou vetor é uma estrutura de dados indexada
Array é uma alocação de variável, com a diferença que ele pode armazenar vários dados.
O array trabalha com índeces, o índece sempre inicia em 0.
Uso do array:
- Simplificar o código
- Estrutura de dados (manipular os dados - banco de dados)
