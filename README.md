# Sobre

JavaScript é uma linguagem de programação de alto nível, dinâmica e interpretada, amplamente usada para criar interatividade em páginas web. Juntamente com HTML e CSS, 
forma a tríade fundamental do desenvolvimento web moderno. Enquanto o HTML é usado para estruturar o conteúdo e o CSS para estilizar, o JavaScript permite adicionar comportamento 
dinâmico às páginas, como interações do usuário, animações, manipulação de dados, e comunicação com servidores.
